# Coming from Windows

## Where things are

| On Windows | Here |
|---|---|
| Start menu | Tap `Super` — type to find apps, files, open windows and settings |
| Taskbar | The dock at the bottom (the **Windows style** layout puts the tray on its right) |
| Notification area / quick settings | The control center: click the sound/battery block on the bar |
| Settings | `Super + I` |
| Task Manager | `Ctrl + Shift + Esc` |
| `Ctrl + Alt + Del` | Same shortcut: suspend, restart, shut down, log out |
| `Win + V` clipboard history | `Super + V` |
| `Win + Shift + S` snipping | `Super + Shift + S` or `Print` |
| `Win + D` show desktop | `Super + D` |
| `Win + L` lock | `Super + L` |
| `Win + Tab` task view | `Super + Tab` |

## What is different

- **Windows tile by default.** New windows share the screen instead of
  piling up. `Super + Shift + V` makes one float; `Super + F` makes it
  fullscreen. In **Settings → Interface Layout** there is an *experimental*
  floating window mode with title bars; minimize and maximize still fail in
  some apps.
- **Workspaces** replace "virtual desktops": `Super + 1…9` jumps between them,
  and they appear and disappear as you use them.
- **Apps come from the package manager**, not from websites. The panel has
  **Programs & Updates** (and, if installed, the Shelly store).
- **Games** run on the NVIDIA card through the rice's game launcher; the rest
  of the desktop stays on the integrated GPU to save battery.

## First things worth doing

1. `Super + I` → **Interface Layout** → try the layouts.
2. Pin your apps: right-click an app in the launcher → *Pin to dock*.
3. `Super + S` → pick a wallpaper; the colors follow it.
4. Set the idle and lock times in **Settings → Power & Battery**.
