# Keyboard shortcuts

`Super` is the Windows key. The same list is on screen with `Super + Shift + F1`,
and you can create or change shortcuts in **Settings → Keyboard Shortcuts**.

## Apps and windows

| Shortcut | Action |
|---|---|
| `Super` (tap) or `Super + R` | Launcher |
| `Super + Q` / `Super + T` | Terminal |
| `Super + E` | File manager |
| `Super + C` or `Alt + F4` | Close the window |
| `Super + F` | Fullscreen |
| `Super + Shift + V` | Float / tile the window |
| `Super + J` | Swap the split direction |
| `Super + Shift + X` | Force-kill a frozen window (click it) |
| `Alt + Tab` | Switch windows (with previews) |
| `Super + Tab` | Overview of all workspaces — `/` searches, drag a window to move it |
| `Super + D` | Jump to an empty workspace (press again to come back) |
| `Super + A` | Show / hide the scratch workspace |
| `Super + Shift + A` | Send the window to the scratch workspace |
| `Super + '` | Drop-down terminal |

## Shell

| Shortcut | Action |
|---|---|
| `Super + I` | Settings panel |
| `Super + F1` | Welcome guide |
| `Super + Shift + F1` | Shortcut list |
| `Super + V` | Clipboard history (`Super + Ctrl + V`: favorites) |
| `Super + N` | Notifications (`Super + Shift + N`: do not disturb) |
| `Super + G` | Quick notes |
| `Super + Ctrl + A` | AI assistant: chat and translation (Ollama locally, or Gemini/OpenAI with your key) |
| `Super + W` | Edit desktop widgets |
| `Super + S` | Wallpaper picker |
| `Super + Esc` or `Ctrl + Shift + Esc` | Task manager |
| `Ctrl + Alt + Del` | Suspend / restart / shut down / log out |
| `Super + L` | Lock the screen |
| `Super + Ctrl + R` | Restart the shell (if something looks stuck) |

## Screen

| Shortcut | Action |
|---|---|
| `Print` or `Super + Shift + S` | Screenshot of a region (Esc cancels) |
| `Shift + Print` | Screenshot of the whole screen |
| `Ctrl + Print` | Screenshot of the active window |
| `Super + Alt + S` | Screenshot and annotate |
| `Super + Shift + T` | Copy the text inside a region (OCR); translation is optional in Settings |
| `Super + Shift + R` | Record the screen (again to stop) |
| `Super + Shift + C` | Color picker |
| `Super + B` | Blur on / off |
| `Super + Shift + B` | Performance mode (blur and animations off) |

## Workspaces

| Shortcut | Action |
|---|---|
| `Super + 1…9` | Go to workspace |
| `Super + Shift + 1…9` | Move the window to workspace |
| `Super + ← / →` | Previous / next workspace (↑ / ↓ with vertical workspaces) |
| `Super + Shift + ← / →` | Take the window to the neighbouring workspace |
| `Super + Alt + arrows` | Move focus between windows |
