# hollow-wired documentation

Guides for people using the rice day to day. For how the project works inside
(architecture, why things are the way they are), see `ESTADO-ATUAL.md` in the
repository root (Portuguese).

- [Getting started](getting-started.md) — first login, the panel, the bar and the dock
- [Keyboard shortcuts](shortcuts.md) — the full list, grouped by task
- [Coming from Windows](coming-from-windows.md) — where things are, and what is different
- [FAQ and troubleshooting](faq.md) — wallpaper, bar, notifications, updates, going back a version

Inside the rice, `Super + F1` opens the welcome guide and `Super + Shift + F1`
shows every shortcut on screen.
